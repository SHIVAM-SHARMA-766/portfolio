Put the portrait here as `profile.jpg` (4:5, at least 800×1000). The path is set in
`content/site.json` (`photo`), and can also be changed in the admin under
Settings → Site & game after uploading under Media.

`profile-cutout.webp` is the same portrait with the background removed (`photoCutout`).
It was made locally with rembg (`isnet-general-use` model, alpha matting); any tool that
outputs a transparent PNG/WebP of the same framing works.

`logo-512.png` is the site mark rendered from `../favicon.svg`.
