Welcome! This course takes you from "what is a container?" to running a multi-service
application with Docker Compose. Every lesson ends with a short quiz — pass it to earn XP.

## What you'll learn

- What containers are, and how they differ from virtual machines
- Running, inspecting and cleaning up containers
- How images and layers work, and why layer order matters
- Writing small, secure Dockerfiles
- Running several services together with Docker Compose

## Before you start

You need a terminal and basic Linux commands (`cd`, `ls`, `cat`). If you don't want to
install anything, every lesson works in a free browser playground such as
[Play with Docker](https://labs.play-with-docker.com/).
